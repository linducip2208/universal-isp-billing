# RADIUS

Native Go: Access-Request/Accept/Reject, Accounting Start/Interim/Stop,
CoA/Disconnect (RFC 5176), NAS management, bandwidth attributes,
session tracking (`SessionStore`), flexible vendor dictionary
(`RegisterVendorAttr` — MikroTik/Cisco/Huawei/ZTE pre-registered).
Run: `RADIUS_AUTH_PORT/ACCT_PORT` (default 1812/1813).
