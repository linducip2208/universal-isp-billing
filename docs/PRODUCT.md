# Product

Universal ISP Network Operating System: one platform for business
(billing/CRM/contracts/SLA/economics), network (NOC/provisioning/
monitoring/topology/twin/RADIUS/SNMP/IPAM/FTTH), and assisted operations
(read-only AI copilot with evidence, anomaly detectors, correlation).

Differentiators (integrated, tested): universal connector SDK 2.0,
desired-vs-actual state + drift, digital twin simulation, service health
composition, impact analysis ("who is affected"), correlation (many alerts
-> one incident), HMAC webhooks, idempotent everything, tenant isolation
proven by live tests.
